미국 증시 마감 리포트 아카이브

날짜는 미국 거래일 기준
사용법
  1. 매일 아침 예약 실행 결과에 첨부되는 us_market_YYYY-MM-DD.json 파일을 리포트 추가로 넣거나 이 화면에 끌어다 놓으면 날짜별로 쌓입니다. 여러 파일을 한 번에 넣어도 됩니다.
  2. 같은 날짜 파일을 다시 넣으면 새 내용으로 바뀝니다.
  3. 추가한 리포트는 이 브라우저에 저장됩니다. 다른 PC로 옮기거나 공유할 때는 HTML로 저장을 눌러 모든 리포트가 들어간 새 파일을 만드세요.
  4. 키보드 ← / → 로 이전·다음 거래일로 이동합니다.
파일을 놓으면 아카이브에 추가됩니다
